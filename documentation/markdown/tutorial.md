# Tutorial

This episode teaches the basic workings and the prototype structure of the language.

You can check the [Language Reference](reference.md#reference-main) episode for the definitions of the syntax rules, and [Wrench Standard Library](stdlib.md#stdlib-main)  for the standard library.

# 1. Hello, World!

Well, hello. Welcome to Wrench! Unlike a lot of languages you’re familiar with that run inside Virtual Machines (or for some, require massive background runtimes), Wrench tries to get you as close to the hardware as possible without forcing you to write raw assembly by hand. It is a native language, which means its code compiles directly into binary machine code.

Let us begin with your very first program and learn how the compiler is used.

## 1.1 Your First Program

Create a file named `hello.wr`. In Wrench, every statement must end with a semicolon (`;`).

```text
print("Hello, World!");
```

That’s it! No need for a `main()` function wrapper or importing massive standard I/O libraries just to print text. Wrench handles it at the kernel level.

#### Versionadded
Added in version 0.1.1: Added support for formatted printing via `printf`. You can interpolate variables directly inside format strings using curly braces `{}` or placeholder specifiers.

```text
var name = "World";
printf("Hello, {name}!\n");
```

## 1.2 The Command Line Interface (CLI) and Flags

The compiler is invoked via the command line. To compile your program, you simply pass the `.wr` source code to be compiled as an input argument:

```bash
python wrench.py hello.wr
```

By default, this will compile the code and generate a native executable named `hello`.

However, the CLI provides several arguments and flags to control the compilation pipeline:

* **\`\`-o\`\` or \`\`–output\`\`**: Sets the executable file name to be produced. If you do not provide this, it defaults to the original file’s name.
* **\`\`-ns\`\` or \`\`–no-strict\`\`**: Turns off strict mode in semantic analyzation. By default, Wrench enforces strict type-checking to keep your memory safe. You can use this flag to bypass those rules during experimental prototyping.
* **\`\`-k\`\` or \`\`–keep\`\`**: Keeps the temporary files created during compilation (`.asm`/`.o`). Normally, Wrench cleans up these intermediate files. Use this flag if you want to inspect the actual x86-64 assembly code generated by the compiler.
* **\`\`-r\`\` or \`\`–run\`\`**: Automatically run the program and delete the executable. This is useful for testing code on the fly without cluttering your directory with binaries.

**Example: Rapid Prototyping**
If you want to quickly test your `hello.wr` script and immediately see the output, just use the run flag:

```bash
python wrench.py hello.wr -r
```

# 2. Variables, Types and Tolerances

Wrench provides a robust static type system, but it does not force you into endless boilerplate. It combines low-level memory safety with high-level developer ergonomics.

## 2.1. Primitive Types & Inference

Wrench supports standard primitve types that map directly to hardware registers. You can declare variables explicitly using `int`, `double`, `str`, `char`, and `bool`.

#### Versionchanged
Changed in version 0.1.1: The null/empty evaluation type previously referred to as `void` is now consistently named `unit`.

```text
int health = 100;
double pi = 3.14;
str greeting = "Welcome to Wrench";
bool is_active = true;
```

If you don’t want to type out the explicit data type, you can use the `var` keyword. The Wrench compiler will infer the type based on the assigned value during compilation. Once inferred, the type is statically locked.

```text
var score = 50;        // Inferred as int
var username = "Root"; // Inferred as str
```

## 2.2. Ergonomics, Case Sensivity & Operator Tolerance

Wrench introduces several unique quality-of-life features to make writing code easier, faster and less error-prone.

**Hybrid Case Sensivity:**
Wrench has a unique way in handling letter casing. All built-in language keywords (like `if`, `while`, `define`, `int`) are **case insensitive**. The Lexer automatically normalizes them, meaning `DeFiNe` and `define` are treated exactly the same. However, your custom identifiers (variable names, function names, and classes) remain **case-sensitive**.

> **Operator Tolerance:**

In many languages, accidentally typing `=+` instead of `+=` throws a syntax error that’s annoying as hell. In Wrench, the Lexer is tolerant of directional typos for compound assignments.

```text
var x = 10;
x =+ 5; // Perfectly valid, identical to x += 5;
x -= 2; // Identical to x =- 2;
```

Furthermore, to eliminate the notorious `=` (assignment) vs `==` (comparison) bugs found in C-like languages, Wrench uses a distinct equality operator: `=?`. `?=` is also perfectly valid.

```text
if (x =? 13) {
    print("x is exactly 13"); // No sh sherlock
}
```

*Reminder: Never forget your semicolons (\`\`;\`\`)! It’s required for all assignments, returns, and function calls.*

## 2.3. Deep Dive: Type Casting

Because Wrench operates in strict mode by default, you cannot implicitly mix incompatible types. Instead, you use the `cast` keyword. The `cast` operator is incredibly powerful and serves three distinct purposes in Wrench:

**1. Primitive Conversions:**
Used to convert standard data types. For example, converting an integer into a string for terminal output, or safely flooring a double to an integer.

```text
var age = 25;
var text = age cast str; // Dynamically allocates a string representation of 25
```

**2. Object Hierarchy (Upcasting & Downcasting):**
When working with Object-Oriented structures, `cast` allows you to navigate inheritance trees. While assigning a child object to a parent variable (Upcasting) is handled implicitly by the compiler, bringing a parent reference back to a child type (Downcasting) requires an explicit cast.

```text
Character enemy = new Goblin();     // Implicit Upcast
var goblin_ref = enemy cast Goblin; // Explicit Downcast
```

**3. Raw Memory Reinterpretation:**
For low-level systems programming, `cast` is used to forcefully interpret raw memory addresses (like `hex` or `ptr` types) into usable data types or class structures, similar to how `reinterpret_cast` works in C++. This is essential when reading incoming data from network sockets, hardware buffers, or custom memory allocators.

# 3. Control Flow and Loops

Wrench takes the flow concepts that you’re probably already familiar with and streamlines them, eliminating common sources of bugs like switch fall-throughs and ambiguous keywords.

## 3.1. Conditions & Branching

Wrench uses standard `if` and `else` blocks, but it introduces `butif` as a replacement for `else if` or `elif`.

```text
var status = 200;

if (status =? 200) {
    print("OK");
} butif (status =? 404) {
    print("Not Found");
} else {
    print("Unknown Error");
}
```

**The Switch Statement (No Fall-Through):**
In languages like C or C++, forgetting a `break;` statement inside a `switch` block causes the code to “fall through” and accidentally execute the next case. This is a notorious source of bugs. Wrench completely eliminates this risk. Every `case` block automatically breaks at the end. You never have to write `break;` manually.

```text
var opcode = 1;

switch (opcode) {
    case 0:
        print("Halt");
    case 1:
        print("Add");
    default:
        print("Unknown Opcode");
}
```

## 3.2. Foreach Logic and Loops

Wrench provides a standard `while` loop that runs as long as its condition evaluates to true.

```text
var count = 0;
while (count < 3) {
    print_int(count);
    count += 1;
}
```

For iterating over collections, Wrench uses a `for ... in ...` syntax. This acts as a “foreach” loop, automatically extracting each element from an array without needing manual index tracking or length calculations.

```text
var weapons = ["Sword", "Bow", "Axe"];

for weapon in weapons {
    print(weapon);
}
```

## 3.3. The ‘limits’ Function and Loop Control

When you need to loop over a specific numerical range, you use Wrench’s built-in `limits(start, end)` function.

**Important Difference:** If you are coming from Python, you might expect `range(1, 5)` to generate numbers from 1 up to 4, stopping before the final number. Wrench’s `limits` function is **inclusive** of the target number. Calling `limits(1, 5)` will generate exactly `1, 2, 3, 4, 5` (By the way Python rules, even though i don’t think it’s much, i highly think it’s slightly underestimated in the world of coding).

```text
for i in limits(1, 5) {
    print_int(i); // Prints 1, 2, 3, 4, 5
}
```

**Loop Control (break & goon):**
Wrench uses standard loop control mechanisms but renames one keyword.

* `break;` : Immediately exits and terminates the nearest enclosing loop.
* `goon;` : (Short for “Go On” -i know what it sounds like- ). This replaces the traditional `continue` keyword. It skips the rest of the current iteration and forces the loop to proceed to the next element.

```text
for i in limits(1, 10) {
    if (i =? 5) {
        break; // Stops the loop entirely when i is 5
    } butif (i % 2 =? 0) {
        goon;  // Skips the print statement for even numbers
    }

    print_int(i); // Will only print 1, 3
}
```

# 4. Functions

Functions in Wrench are straightforward. They map directly to hardware-level jumps and strictly follow the kernel calling conventions (Current version only supports System V ABI conventions, which are used by Unix-like operating systems like the Linux kernel. If you want to learn more about it, you can check the OS Dev Wiki here_ <https://wiki.osdev.org/System_V_ABI>).

## 4.1. Basic Functions

To create a standard function, use the `define` keyword followed by the function name and its parameter list. Wrench uses static typing for parameters, but you do not need to explicitly declare the return type in the function signature—the compiler infers it dynamically based on what you return.

#### Versionadded
Added in version 0.1.1: Functions now support explicit return type syntax using the arrow operator `-> ReturnType`.

```text
define greet_user(str name) -> unit {
    print("Welcome back, " + name);
}

greet_user("Admin");
```

To return a value from a function, use the `return` keyword. If you just want to exit a function early without returning a specific value, you can simply write `return;`.

```text
define calculate_area(int width, int height) {
    if (width <= 0 or height <= 0) {
        return 0; // Early exit for invalid dimensions
    }

    var area = width * height;
    return area;
}

var room_area = calculate_area(5, 4);
```

## 4.2. Anonymous Functions (Anfuncs)

Sometimes you need a function for a quick, one-off operation, or you want to pass a function around as a variable. Wrench supports anonymous functions via the `anfunc` keyword.

An `anfunc` does not have a name. Instead, you assign it directly to a variable. This makes functions “first-class citizens” in Wrench, allowing you to treat executable code blocks just like regular data pointers.

```text
// Assigning an anonymous function to a variable
var multiply = anfunc(int a, int b) {
    return a * b;
};

// Calling it dynamically
var result = multiply(10, 5);
print_int(result); // Prints 50
```

*Note: Since assigning an anonymous function to a variable is a variable assignment statement, do not forget to put a semicolon (\`\`;\`\`) at the very end of the closing brace \`\`};\`\`.*

# 5. Arrays and Deep Memory Management

Wrench gives you the raw power of memory management (which i strongly support, in a world where every possibility and right is being stripped away, including the internet and the computing), but takes some safety measures where it actually matters.

## 5.1. Arrays and Safety

All you have to do to crate an array is to use two square brackets:

```text
var weapons = ["Sword", "Bow", "Axe"];
print(weapons[1]); // Prints "Bow"
```

**The Hidden Header Architecture:**
When you create an array (or allocate memory), Wrench automatically requests an extra 8 bytes of memory and places them invisibly right before your actual data. This “hidden header” permanently stores the length or size of your array in RAM.

**Out-of-Bounds Protection:**
In older low-level languages, trying to read `weapons[10]` would silently read garbage memory or cause a Segmentation Fault.Wrench, checks the hidden header first automatically every array access. If the index is invalid, the compiler halts the operation and throws an Error (Code 99). This prevents crashes and allows you to handle the mistake.

## 5.2. Manual Memory Management

Wrench **does not** have a Garbage Collector (GC). Garbage collectors consume unpredictable CPU cycles and memory, which is not very compatible with low-level programming (Although, there will be an optional Garbage Collector developed in the later versions).

You are fully in charge. What you create, you must destroy. Or accept that at some point the program is going to crash.

**Raw Pointers (ptr and address):**
When dealing with custom memory buffers or hardware addresses, you often work with raw pointers. In Wrench, you can explicitly type variables as `ptr`, `address`, or `hex`. A pointer is simply a numeric variable that holds the physical RAM address of your data, rather than the data itself.

## 5.3. Allocation and Cleanup (alloc & delete)

When you need a custom block of memory (like a dynamic text buffer or a network packet payload), you ask the Operating System for it using the built-in `alloc()` function.

`alloc()` talks directly to the kernel using Syscall 9 `mmap` to reserve raw memory (Future versions will include Win64 ABI, AArch64 macOS ABI and x86-64 macOS ABI. For details, see the [Roadmap](roadmap.md#roadmap-main).).

```text
// Ask the OS for 1024 bytes of raw memory
var buffer = alloc(1024);
```

**The Danger of Memory Leaks:**
Because there is no Garbage Collector, the OS assumes you are still using that memory until you explicitly give it back. If your function ends and you forget to return the memory, it becomes a “Memory Leak”—lost space that cannot be used again until your program completely shuts down (Which will probably be thing that causes the crashes i mentioned earlier).

**The ‘delete’ Keyword:**
To safely return memory to the OS and prevent leaks, you must use the `delete` keyword. This instructs to read the hidden header of your pointer and triggers Syscall 11 (`munmap`) to instantly free the exact block of memory (Future versions will include Win64 ABI, AArch64 macOS ABI and x86-64 macOS ABI. For details, see the [Roadmap](roadmap.md#roadmap-main).).

```text
define process_data() {
    var buffer = alloc(1024);

    // ... do heavy work with the buffer ...

    delete buffer; // Safely return memory to the OS!
}
```

# 6. Object-Oriented Basics

While Wrench is a low-level systems language, it provides an Object-Oriented Programming model to help you structure complex data easily. Objects are just contiguous blocks of memory, but Wrench makes them act high-level at the user end.

## 6.1. Classes and Constructors

You define an object’s blueprint using the `class` keyword. Inside a class, you can declare variables (fields) and functions (methods).

To initialize an object when it is created, you define a special method called `init`. Inside any method, you can use the `this` keyword to access the specific instance of the object.

```text
class Player {
    int health;
    str name;

    // The constructor
    define init(str player_name) {
        this.name = player_name;
        this.health = 100;
    }

    define take_damage(int amount) {
        this.health -= amount;
        print(this.name + " took damage!");
    }
}
```

## 6.2. Instantiation and Inheritance

To create an actual object from your class, you use the `new` keyword. This automatically calculates the size of the class, allocates the exact amount of memory needed via the kernel, and calls your `init` method.

Wrench also supports single inheritance using the `extends` keyword. A child class automatically inherits all the memory layout (fields) and methods of its parent.

```text
class Boss extends Player {
    int armor;

    define init(str boss_name) {
        this.name = boss_name;
        this.health = 500;
        this.armor = 50;
    }
}

// Instantiating objects using 'new'
var hero = new Player("Arthur");
var dragon = new Boss("Fire Drake");

hero.take_damage(20);
```

Again, it apprarently has no Garbage Collector, remember that objects created with `new` live in dynamically allocated memory. If you are destroying an object permanently, you should pass it to `delete` to avoid memory leaks.

# 7. Safety and Concurrency

Wrench handles errors and concurrency directly at the kernel level, bypassing any runtime.

## 7.1. Preventing Crashes (attempt, exclude, final)

Wrench traps fatal hardware errors, such as Segmentation Faults, using OS signal handlers. Instead of crashing, it routes the execution to safe blocks using three keywords:

* **\`\`attempt\`\`**: The code block you want to run safely.
* **\`\`exclude\`\`**: Executes if a crash occurs. The compiler automatically injects an `err` variable containing the error code here.
* **\`\`final\`\`**: Always executes, regardless of errors.

```text
attempt {
    var arr = limits(0, 5);
    print(arr[10]); // Throws an Out-of-Bounds error
} exclude {
    print("Error caught! Code: ");
    print_int(err); // 'err' is automatically available
} final {
    print("Cleanup complete;");
}
```

## 7.2. Background Tasks (async and when)

Wrench achieves concurrency through real multi-processing (forking) rather than user-space threads.

**Async Functions:**
Prefixing a function with `async` tells the compiler to run it in a completely separate OS process. The main program continues without blocking.

```text
async define background_task() {
    // Heavy work runs in parallel
}
background_task();
```

**Polling with ‘when’:**
The `when` keyword forks a lightweight background process that sleeps and continuously polls a condition. When the condition becomes true, it executes its block and terminates.

```text
var system_ready = false;

when (system_ready =? true) {
    print("System is ready!");
}

// ... other code ...
system_ready = true; // The background observer detects this and fires.
```

# 8. Modularity and External Libraries

Wrench allows you to split your project into manageable pieces and seamlessly integrate with other low-level languages.

## 8.1. Wrench Modules (include)

You can import other Wrench (`.wr`) files using the `include` keyword. The compiler automatically resolves these files and merges their Abstract Syntax Trees before generating machine code.

```text
include "math_utils"; // Automatically looks for math_utils.wr
```

To keep your global scope clean, you can import specific functions, classes, or variables using the `from ... include` syntax. You can also rename imported items using the `as` keyword to prevent naming collisions.

```text
from "math_utils" include calculate_area as get_area;
```

## 8.2. Connecting to the Outside World (link & extern)

Wrench can natively interoperate with pre-compiled binaries written in C, C++, or raw Assembly.

Use the `link` keyword to instruct the compiler to pass an external object file (`.o`) to the GNU Linker (`ld`) during the final build stage.

```text
link "physics_engine.o";
```

Once the external file is linked, you must declare its functions in Wrench using the `extern` modifier. This tells the compiler that the function body exists outside of your Wrench code.

```text
// Declare the external function
extern define apply_gravity(int mass);

// Call it natively in Wrench
var result = apply_gravity(100);
```
