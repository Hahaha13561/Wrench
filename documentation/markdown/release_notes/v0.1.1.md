# Wrench v0.1.1 Release Notes

Version 0.1.1 is a feature and cleanup release focusing on semantic analyzer integration with code generation, compiler backend hardening, parser/lexer expansions, and a newly added suite of standard library modules.

## New Standard Library Modules

* `std/argparser.wr`: Argument parsing library supporting `Argument`, `ArgumentParser`, flags, actions, and subparsers.
* `std/clone.wr`: Memory cloning, array cell swapping, target memory filling, and dynamic `clone()` helpers.
* `std/os.wr`: Path operations (`join`, `dirname`, `normpath`, `abspath`) and OS subsystem helpers (`getcwd`, `remove`, `rmdir`, `makedirs`, `access`, `getenv`) with OS error mapping].
* `std/regex.wr`: Regular expression matching utilities including `compile`, `match`, `finditer`, `split`, and `sub`.
* `std/subprocess.wr`: Process management and IPC library utilizing native x86-64 Linux syscalls (`SYS_FORK`, `SYS_EXECVE`, `SYS_PIPE`, `SYS_DUP2`, `SYS_WAIT4`, `SYS_KILL`) with `Popen` and `CompletedProcess` abstractions].

## Compiler Backend & Code Generation (codegen.py)

* **Semantic Integration**: Synchronized `CodeGen` with `SemanticAnalyzer` to pass return-type metadata, strict variable types, and class member structures.
* **Isolated Function Section**: Decoupled free functions, methods, and anonymous functions into a dedicated `functions_code` assembly block linked into the executable entry point.
* **Conditional & Formatting Optimizations**:
  * Implemented `generate_branch` to convert boolean conditions directly into inverse jump assembly instructions.
  * Added format string parsing and placeholder AST construction for native `printf` support.
* **Assembly Routine Enhancements**:
  * Added and updated runtime assembly routines: `print_string` (null checking), `print_hex`, `concat_strings`, `compare_strings`, `alloc`, `get_mem32`, and `get_len`.
  * Replaced 64-bit register moves with 32-bit register alternatives for stack space optimization,
  * Unified function exit labels and strengthened array bounds checking with SIGSEGV stack recovery.

## Parser & Lexer Improvements (parser.py / lexer.py)

* **Explicit Return Types**: Added function and method return-type syntax support via the `->` (ARROW) token.
* **Identifier Validation**: Added `expect_identifier` helper and `BUILTIN_FUNCTION` protections to prevent keywords or built-in routines from being redefined as identifiers.
* **Error Diagnostics**: Added token context window logging for syntax parse errors.

## Semantic Analyzer (semantic.py)

* **Type Tracking & Hierarchy**: Expanded semantic checks to track function signatures, class methods, class fields, and inheritance hierarchies.
* **Built-in Type Map**: Added `BUILTIN_FUNCTION_TYPES` mapping to enforce proper call/return evaluation for language built-ins.
* **Evaluation Tagging**: Extended visitor rules across AST nodes (Blocks, Conditions, Loops, Returns, Assignments, Class Definitions, Index Access) to infer and validate `eval_type`.

## CLI & Pipeline (wrench.py)

* Updated execution workflow ordering: Tokenize -> Parse -> Resolve Imports -> Semantic Analysis -> CodeGen.
* Improved import alias resolution to preserve line and column metadata.
* Added traceback logging on compilation exceptions.

## Standard Library Refactoring & I18n

* **Explicit Type Signatures**: Annotated standard library functions with return types (`->`) across `collections`, `string`, `fs`, `math`, `time`, and `sys`.
* **SysModule Migration**: Restructured `std/sys.wr` into a structured `SysModule` object.
* **Cleanup & Translation**: Removed embedded inline test harnesses across standard library files and translated Turkish error messages/comments into English.
